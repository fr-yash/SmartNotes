================================================================================
                        QUICK REFERENCE
================================================================================

PROJECT STRUCTURE:
- Backend: Node.js + Express.js + MongoDB
- Frontend: React + Vite + Tailwind CSS
- AI: Google Gemini API
- Auth: JWT tokens

MAIN FEATURES:
1. User Authentication & Authorization
2. Note Management (CRUD + Sharing)
3. AI-Powered Features (Summarize, Keywords, Rewrite, Ask, Quiz)
4. PDF Management
5. Admin Dashboard
6. User Suspension & Appeal System
7. Export Functionality

KEY MODELS:
- User (authentication, roles, suspension)
- Note (content, sharing, ownership)
- SuspensionRequest (appeals, admin responses)

MAIN ROUTES:
- /api/auth - Authentication
- /api/notes - Note management
- /api/ai - AI features
- /api/pdf - PDF management
- /api/admin - Admin operations
- /api/suspension-requests - Appeals

SECURITY:
- JWT authentication
- Role-based access control
- Password hashing (bcrypt)
- Account suspension
- Rate limiting (100 AI requests/day)
